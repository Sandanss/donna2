|---|---------|-------------|-----------|---------|-------------------|--------|
| 1 | Admin Dashboard Revamp | Scope and build out a revamp of the admin dashboard for tracking individual user usage of Donna. Should surface per-user metrics: missed vs answered call rates, average call duration, reminder usage, topics discussed, and engagement trends. Requires a scoping discussion between Nick and David on layout and data views before any build work begins. | Once we have a few dozen users, we need user-level visibility into how each senior is engaging with Donna — not just aggregate stats. This will inform product decisions and help us identify at-risk users or underutilized features. | Low | — | Not Started |
| 2 | Dynamic Reminder Creation & Call Scheduling (Ask Donna in App) | Port and improve the existing "Ask Donna" chat feature from the website into the mobile app. The web version has known rough edges — the app version should improve on the UX, especially for bulk operations (e.g., scheduling a call 5 minutes before all 82 Dallas Mavericks games with a "tune in" reminder, in one shot). Key learnings from the app build should then be backported to the website. | Caregivers need a fast, natural way to set call times and reminders — especially in bulk. The current web "Ask Donna" is a start but isn't polished enough for the primary caregiver surface (the app). Making this seamless reduces friction and increases reminder adoption. | Medium | — | Not Started |
| 3 | Direct Data Feeds for Factual Queries | Investigate and implement direct data feeds (sports scores/schedules, weather, etc.) as an alternative or supplement to web search (Tavily) for questions with definitive answers. Current web search is competitive but unreliable for real-time factual queries (e.g., game times) — Alexa handles these correctly nearly every time using structured data feeds rather than web scraping. Requires research into which query categories seniors use most, available data APIs, and cost/complexity trade-offs. | To position Donna as a viable Siri/Alexa equivalent for seniors, she needs to reliably answer direct factual questions (game times, weather, stock prices, etc.). Web search works for open-ended queries but isn't accurate or fast enough for structured data. Understanding what seniors actually ask Donna will help prioritize which feeds to integrate first. | Low-Medium | — | Not Started |
| 4 | Timezone Management | Audit and fix how timezones work across the app and website. All scheduled call times should be in the senior's timezone by default. Known issues: some accounts default to Central time despite onboarding specifying Eastern or Pacific locations. Cross-timezone scenario must work correctly — if a caregiver on Eastern sets a call for 12pm for their West Coast senior, the senior should be called at 12pm Pacific (not 9am). Requires end-to-end audit of timezone handling in onboarding, scheduling, Ask Donna, and display layers. | Important standalone, but also a dependency of the Ask Donna mega-feature — dynamic scheduling via chat creates more edge cases when timezone logic is unreliable. Needs to be solid before bulk scheduling features ship. | Low-Medium | — | Not Started |
| 5 | Agentic Workflows for Seniors | Design Donna to deliver a "non-technical-user OpenClaw-adjacent experience over the phone." Only after significant user base growth and clear demand signals, explore enabling action-taking services: Amazon ordering, party planning (invite friends, order food via Instacart), and ride scheduling (calling Ubers). Ride calling example: a senior who can't drive calls Donna to schedule an Uber for an appointment — Donna books the ride and calls back 10 minutes before pickup to remind them the driver is coming. | If users demonstrate they enjoy phone-based AI interaction and want more functionality, agentic workflows could attract a broader segment of more independent seniors. High upside if demand materializes — transforms Donna from an assistant into a full concierge. Only pursue after clear pull from users. | Very Low | — | Not Started |
| 6 | Donna Texts Seniors | Build SMS/text-based interactions where Donna proactively texts seniors with reminders, updates on topics they care about, and other timely information — similar to how Stella Foster works via text. Would operate as a complementary channel alongside phone calls, not a replacement. | If we find that many seniors are capable texters who'd prefer quick text updates over full phone calls for certain use cases (reminders, weather, game scores), this opens another engagement channel. Likely becomes more important if we attract younger, more tech-comfortable seniors who want an assistant but don't always want to talk. | Low | — | Not Started |
| 7 | Brain Games | Build Donna's ability to play cognitive games during calls — trivia, 20 questions, word association, and other brain exercises that help with memory and mental sharpness. Could be offered as a dedicated "game time" call or woven into regular conversations when the senior is in the mood. Competitors offer this but existing implementations aren't great — opportunity to do it better. | Incremental value prop that competitors already market. Differentiator if executed well (natural, fun, adaptive difficulty vs. robotic quiz formats). Adds engagement time and gives caregivers another reason to subscribe — "Donna keeps Mom's mind sharp." | Low | — | Not Started |
| 8 | Family Mapping | Within the Loved One Profile section, add a dedicated area for caregivers to upload/list all relevant people in a senior's life — kids, grandkids, friends, doctors, caretakers — with names, roles, phone numbers, and descriptions. Donna can then reference these people in calls: asking the senior about favorite memories with them, sharing stories the caregiver provided, or gently reminding them who someone is. Still needs scoping on exact purpose and implementation approach. | Particularly valuable for seniors with memory loss — Donna becomes a tool for recalling and discussing the people in their life. Caregivers can provide context (stories, relationships) that Donna uses to spark warm, personalized conversations. Bridges the gap between "Donna knows about you" and "Donna knows your world." | Low | — | Not Started |
